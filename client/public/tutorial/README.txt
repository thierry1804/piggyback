Captures d'écran du tutoriel
============================

Pour illustrer le tutoriel, placez ici des images nommées :

  step1.png  - Accueil / bouton "Ouvrir l'app"
  step2.png  - Création d'un objectif (dialogue)
  step3.png  - Ajout ou retrait d'argent (carte objectif ou détail)
  step4.png  - Tableau de bord et détail d'un objectif (graphique)
  step5.png  - Page Paramètres
  step6.png  - (optionnel) Résumé / hors-ligne

Format recommandé : PNG ou WebP, ratio 16:9 (ex. 800×450 px).
Si un fichier est absent, un placeholder "Capture d'écran" s'affiche.
